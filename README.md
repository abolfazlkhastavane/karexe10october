# برنامهٔ مطالعاتی — نسخهٔ ۲

بازسازی کامل برنامهٔ دسکتاپ «برنامهٔ مطالعاتی» (که فایل اصلی‌اش
`karkar__1_.py` بود) با دو بخش:

| پوشه | شرح |
|---|---|
| [`app/`](./app/README.md) | برنامهٔ دسکتاپ — حالا با رابط وب مدرن داخل یک پنجرهٔ بدون‌قاب (بدون ظاهر مرورگر)، آمادهٔ تبدیل به exe |
| [`worker/`](./worker/README.md) | سامانهٔ لایسنس + پنل مدیریت، روی Cloudflare Workers (جایگزین `licance.ercc.ir`) |
| `dev-tests/` | تست خودکار رابط کاربری (اختیاری، فقط برای توسعهٔ بیشتر) |

## ساخت خودکار فایل اجرایی ویندوز (EXE) با GitHub Actions

اگر به سیستم ویندوز دسترسی ندارید، می‌توانید ساخت فایل `.exe` را کاملاً به **GitHub Actions** بسپارید:

1. تغییرات و پروژهٔ خود را به ریپازیتوری گیتهاب `push` کنید.
2. در تب **Actions** در بالای صفحهٔ گیتهاب، گردش‌کار **Build Windows Executable** را مشاهده کنید.
3. پس از پایان ساخت (تیک سبز رنگ)، وارد آخرین ساخت شده و از بخش **Artifacts**، فایل زیپ `BarnameMotaleati-Windows` را دانلود کنید.
4. فایل زیپ شامل تمامی بسته‌های موردنیاز، فونت‌ها و فایل خروجی اجرایی برنامه به صورت کاملاً تست‌شده و تضمینی روی ویندوز می‌باشد.

## ترتیب پیشنهادی راه‌اندازی

1. اول **`worker/README.md`** را دنبال کنید و سامانهٔ لایسنس را روی
   Cloudflare بسازید (۱۰-۱۵ دقیقه، فقط با کلیک در سایت Cloudflare، بدون
   نصب هیچ ابزاری) و حداقل یک کد لایسنس بسازید.
2. سپس **`app/README.md`** را دنبال کنید: فایل‌های سورس درسی/قالب‌ها/
   تصاویر خودتان را کپی کنید، برنامه را اجرا کنید، آدرس Worker را در
   تنظیمات وارد کنید، با کد لایسنسی که ساختید فعال‌سازی کنید.
3. در پایان، طبق بخش «تبدیل به فایل اجرایی ویندوز» در `app/README.md` یا با استفاده از GitHub Actions،
   فایل exe را بسازید و پوشهٔ خروجی را به مشتری تحویل دهید.

## خلاصهٔ تغییرات نسبت به نسخهٔ قبلی

- ✅ همهٔ قابلیت‌های قبلی حفظ شده: مدیریت سورس‌های درسی، قالب‌ها، کدهای
  درسی، ادغام خانه‌ها، ویرایش دستی/گروهی/جایگزینی/درج‌وشیفت، ذخیرهٔ
  انتخاب به‌عنوان قالب، خروجی Word، خروجی «لوکس PDF».
- 🎨 رابط کاربری کاملاً بازطراحی‌شده، مدرن‌تر و راحت‌تر، با پنجرهٔ بدون‌قاب
  (بدون ظاهر مرورگر) بر پایهٔ موتور مرورگر سیستمی.
- ✏️ جملات انگیزشی، رنگ تم و تعداد روز پیش‌فرض از داخل برنامه قابل‌ویرایش‌اند؛
  عنوان برنامه و آدرس سرور لایسنس عمداً ثابت و داخل کد هستند.
- 🔤 فونت وزیر با یک اسکریپت (`app/download_vazir_font.py`) دانلود می‌شود و در
  رابط برنامه، خروجی PDF و Word استفاده می‌شود.
- 🔑 سامانهٔ لایسنس روی Cloudflare Workers + D1، با پنل مدیریت تحت وب برای
  ساخت/غیرفعال‌سازی/حذف لایسنس‌ها — دیپلوی کاملاً از طریق سایت
  Cloudflare، بدون Wrangler.
- 📦 آمادهٔ تبدیل به exe با PyInstaller و build خودکار ویندوز از طریق GitHub Actions.
