# برنامهٔ مطالعاتی — نسخهٔ ۲ (رابط وب در پنجرهٔ بومی)

این پوشه، بازنویسی کامل برنامهٔ دسکتاپ قدیمی (PyQt5) است. تمام قابلیت‌های
قبلی حفظ شده‌اند، اما:

- به‌جای پنجرهٔ Qt، یک **رابط وب مدرن** داخل یک **پنجرهٔ بدون‌قاب** (بدون
  آدرس‌بار، تب یا هر نشانهٔ دیگری از مرورگر) نمایش داده می‌شود — از موتور
  مرورگر داخلی ویندوز (WebView2 / Edge) استفاده می‌کند ولی ظاهرش کاملاً
  شبیه یک اپلیکیشن مستقل است.
- جملات انگیزشی از دکمهٔ «💬 جملات انگیزشی» در هدر برنامه و رنگ تم / تعداد
  روز پیش‌فرض از ⚙️ تنظیمات قابل‌ویرایش‌اند. **عنوان برنامه و آدرس سرور لایسنس
  ثابت و داخل کد هستند** (`core/config.py` ← `APP_TITLE` و `LICENSE_API_URL`) و
  از بیرون قابل تغییر نیستند.
- بعد از ورود، پنجرهٔ «📋 اطلاعات اصلی» (نام دانش‌آموز و تعداد روز) خودکار باز
  می‌شود؛ می‌توانید ببندید و هر وقت خواستید از دکمهٔ هدر دوباره باز کنید.
  پنل «انتخاب درس» و «پیش‌نمایش» همیشه سر جایشان هستند.
- سامانهٔ لایسنس قدیمی (`licance.ercc.ir`) با یک **Worker اختصاصی روی
  Cloudflare** جایگزین شده (پوشهٔ `../worker`، به همراه پنل مدیریت تحت وب).
- کد برای تبدیل به exe با PyInstaller/auto-py-to-exe یا **GitHub Actions** آماده شده (مسیرهای
  فایل، چه در حالت توسعه و چه بعد از پکیج‌شدن، به‌درستی مدیریت می‌شوند).

## ساخت خودکار بدون نیاز به ویندوز (GitHub Actions)

اگر رو کامپیوتر خودتون سیستم‌عامل ویندوز ندارید، نیازی به نصب ویندوز یا ماشین مجازی نیست!
تنها کافیست کدها را به گیتهاب `push` کنید تا **GitHub Actions** روی سرورهای ویندوزی گیتهاب به طور خودکار فایل اجرایی را بپزد و فایل زیپ آماده خروجی (`BarnameMotaleati-Windows.zip`) را در تب **Actions** > **Artifacts** برای دانلود قرار دهد.

## ساختار پوشه‌ها

```
app/
  main.py, api.py, core/      ← کد برنامه (بعد از build داخل exe می‌رود)
  web/                         ← رابط کاربری HTML/CSS/JS (همراه exe باندل می‌شود)
  build.spec                   ← تنظیمات PyInstaller
  requirements.txt

  --- فایل‌ها و پوشه‌های زیر «دادهٔ کاربر» هستند: کنار exe (یا کنار main.py
      در حالت توسعه) قرار می‌گیرند، قابل‌ویرایش‌اند و با آپدیت برنامه از
      بین نمی‌روند ---
  *.xlsx                       ← هر فایل، یک «سورس درسی» (دقیقاً مثل قبل)
  templates/                   ← قالب‌های محتوای روز‌به‌روز
  aks/                         ← تصاویر برند + all-s.xlsx / all-l.xlsx
  fonts/                       ← فونت وزیر (با download_vazir_font.py دانلود می‌شود)
  lesson_codes.json, settings.json, motivational_sentences.json,
  license_config.json, schedule_app.log   ← همه به‌صورت خودکار ساخته می‌شوند
```

فایل‌های `.xlsx` سورس‌های درسی و پوشهٔ `aks/` و `templates/` از نسخهٔ قبلی
خودتان را مستقیم داخل همین پوشه (کنار `main.py`) کپی کنید — بدون هیچ تغییری
کار می‌کنند.

## اجرا در حالت توسعه

```bash
cd app
python -m venv .venv
.venv\Scripts\activate        # ویندوز
pip install -r requirements.txt
python main.py
```

ابتدا آدرس Worker خودتان را (طبق `../worker/README.md`) در `core/config.py` ←
`LICENSE_API_URL` بگذارید. در هر اجرا صفحهٔ «فعال‌سازی برنامه» نمایش داده
می‌شود؛ اولین بار کد لایسنس را وارد کنید، دفعات بعد کد قبلی در فیلد پر است و
فقط دکمهٔ «فعال‌سازی» را بزنید (یا کد را عوض کنید).

### تست بدون لایسنس (فقط هنگام اجرا از روی سورس)

```bash
# PowerShell
$env:SCHEDULER_SKIP_LICENSE="1"; python main.py
# cmd
set SCHEDULER_SKIP_LICENSE=1 && python main.py
```

این حالت فقط وقتی کد با `python main.py` اجرا شود کار می‌کند؛ در exe ساخته‌شده
به‌طور کامل غیرفعال است.

## فونت وزیر

```bash
python download_vazir_font.py            # دانلود ۶ وزن رسمی به پوشهٔ fonts
python download_vazir_font.py --install  # + نصب برای کاربر فعلی ویندوز (برای خروجی Word)
```

برنامه همهٔ وزن‌ها را خودکار بارگذاری می‌کند و در خروجی PDF هم فونت داخل خود
فایل جاسازی می‌شود. خروجی Word فقط «نام» فونت را ذخیره می‌کند؛ برای دیده‌شدن
وزیر، فونت باید روی سیستم بازکنندهٔ فایل نصب باشد (گزینهٔ `--install`).

## تنظیمات قابل‌ویرایش از داخل برنامه

- **⚙️ تنظیمات:** رنگ اصلی تم (کد HEX) و تعداد روز پیش‌فرض برنامهٔ جدید.
- **💬 جملات انگیزشی (دکمهٔ هدر):** فهرست کامل قابل‌افزودن/حذف/ویرایش (از
  `{{name}}` برای جای نام دانش‌آموز استفاده کنید).

## تبدیل به فایل اجرایی ویندوز (exe)

### روش اول (توصیه‌شده برای کسانی که ویندوز ندارند): GitHub Actions
به تب **Actions** در مخزن گیتهاب بروید و فایل زیپ ساخته‌شده را دانلود کنید.

### روش دوم: PyInstaller با فایل build.spec آماده دستی روی ویندوز

```bash
cd app
pip install pyinstaller
pyinstaller build.spec
```

خروجی در `dist/BarnameMotaleati/` ساخته می‌شود. **کل همین پوشه** را منتقل
کنید (نه فقط فایل exe)، چون فایل‌های سورس‌های درسی/قالب‌ها/تنظیمات کنار
همان exe ساخته و ذخیره می‌شوند.

### روش جایگزین: auto-py-to-exe (همان‌طور که خواسته بودید)

```bash
pip install auto-py-to-exe
auto-py-to-exe
```

در پنجرهٔ باز‌شده:
1. **Script Location** → مسیر `app/main.py` را انتخاب کنید.
2. **Onedir / One Directory** را انتخاب کنید (نه Onefile — استارت سریع‌تر و
   دیباگ راحت‌تر؛ Onefile هم کار می‌کند اما هر اجرا کمی کندتر است).
3. **Console Window** → **Window Based (hide the console)** را بزنید.
4. **Additional Files** → پوشهٔ `app/web` را اضافه کنید (مقصد: `web`).
5. در تب **Advanced**، در قسمت **Hidden Imports** یا از طریق خط فرمان
   `--collect-all webview` را اضافه کنید (این مورد را همان‌جا در کادر
   «Advanced» به‌صورت متنی هم می‌توانید وارد کنید).
6. **CONVERT .PY TO .EXE** را بزنید.

> نکتهٔ فنی: `build.spec` این تنظیمات (از‌جمله collect-all برای pywebview)
> را از قبل به‌درستی انجام داده؛ اگر با auto-py-to-exe به خطای «ماژول پیدا
> نشد» برخوردید، همان روش PyInstaller/build.spec را امتحان کنید که
> مطمئن‌تر است.

### نیازمندی روی سیستم مشتری

ویندوز ۱۰ (نسخهٔ ۲۰۰۴ به بعد) و ویندوز ۱۱ از قبل WebView2 Runtime را همراه
خود دارند، پس معمولاً نیازی به نصب چیز اضافه‌ای نیست. اگر سیستم خیلی
قدیمی باشد، Runtime رایگان مایکروسافت (Evergreen Bootstrapper) باید نصب
شود.

برای خروجی PDF لوکس هم داشتن Microsoft Edge (که در ویندوز پیش‌فرض است)
کافی است.

## چه چیزی نسبت به نسخهٔ قبلی عوض شده؟

- ویرایش درجای خانه‌های جدول دیگر به «تعداد روز» محدود نیست — هر خانهٔ
  نمایش‌داده‌شده قابل‌ویرایش است (در نسخهٔ قدیمی این محدودیت به‌اشتباه
  وجود داشت).
- به‌جای فایل متنی `license.txt`، کد لایسنس مستقیم داخل برنامه وارد
  می‌شود و آخرین کد در فیلد ذخیره می‌ماند.
- به‌جای QPrinter به‌عنوان بازگشتی PDF (که با حذف Qt دیگر وجود ندارد)، در
  صورت نبود Edge/Chrome، کتابخانهٔ اختیاری WeasyPrint امتحان می‌شود (به
  `requirements.txt` مراجعه کنید).
- منطق اصلی (توزیع مباحث روی روزها، ادغام خانه‌ها، جایگزینی/درج‌وشیفت،
  خروجی Word و PDF لوکس) عیناً از نسخهٔ قبلی پورت شده است.

## رفع اشکال رایج

- **صفحهٔ سفید هنگام اجرا** → مطمئن شوید پوشهٔ `web/` کنار exe (داخل
  `dist/BarnameMotaleati`) وجود دارد.
- **خطای اتصال به سرور لایسنس** → `LICENSE_API_URL` در `core/config.py` باید
  دقیقاً به `/api/validate` ختم شود (و پیش از build تنظیم شده باشد)؛ به
  `../worker/README.md` مراجعه کنید.
- **خروجی PDF کار نمی‌کند** → از نصب‌بودن Microsoft Edge روی سیستم مطمئن
  شوید یا `weasyprint` را طبق `requirements.txt` نصب کنید.
- **آنتی‌ویروس فایل exe را مسدود می‌کند** → این مشکل رایج فایل‌های ساخته‌شده
  با PyInstaller روی سیستم‌های جدید است؛ امضای دیجیتال (Code Signing) یا
  افزودن استثنا (Exception) در آنتی‌ویروس مشتریان را در نظر بگیرید.
