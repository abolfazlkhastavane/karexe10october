# تست خودکار رابط کاربری (اختیاری، فقط برای توسعه)

`test_frontend.js` رابط وب برنامه (`app/web/`) را داخل یک DOM شبیه‌سازی‌شده
(jsdom) با یک نسخهٔ جعلی از API پایتون اجرا و رفتار آن را بررسی می‌کند:
انتخاب درس/مبحث، افزودن درس، ویرایش درجای خانه‌ها، انتخاب گروهی و عملیات
روی آن، حذف درس، مدیریت قالب‌ها/دروس، ریست برنامه و اعتبارسنجی خروجی‌ها.

این تست بخشی از خود برنامه نیست و برای اجرای برنامه لازم نیست؛ فقط یک
ابزار کمکی برای توسعهٔ بیشتر است.

اجرا:
```
cd dev-tests
npm install jsdom
node test_frontend.js
```
